Create a minimal functional web tool website with a clean industrial style.

STYLE

The design must be minimal, practical and tool-focused.
Very similar to the style of utility websites used for makers and technical tools.

Design principles:
- minimal layout
- lots of white space
- black and white color palette
- very clear typography
- functional UI
- no decorative elements
- focus on usability

COLOR PALETTE

Background: pure white
Text: black
Secondary text: dark gray
Borders: light gray
Buttons: black with white text

TYPOGRAPHY

Use a modern sans-serif font similar to Inter or system UI.

Font scale:
H1 large bold headline
H2 section titles
Body medium readable text

LAYOUT STRUCTURE

Page width: about 1000px centered.

Page sections:

1. Header
- logo or site name on the left
- minimal navigation on the right

2. Hero section
- big title explaining the tool
- short description
- call to action button

3. Tool interface
- input fields
- action button
- result card

4. Result section
- clean bordered card
- large readable output

5. Explanation section
- short explanation of how the tool works

6. Footer
- minimal links
- copyright

UI COMPONENTS

Inputs:
rounded corners
light gray border
comfortable padding

Buttons:
black background
white text
rounded corners

Result card:
light gray background
subtle border
padding

TONE

Text must be:
clear
technical
direct
no marketing hype
focused on usefulness

EXAMPLE TEXT

Title:
"Online Calculator Tool"

Description:
"Enter your values and get the result instantly."

Button:
"Calculate"
